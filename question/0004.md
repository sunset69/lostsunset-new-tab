# 问题
1. 时钟固定在左下角，无法按喜好调整位置；双击/拖拽时钟、Dock 提示、环境名称等装饰文字时会出现蓝色选中高亮；快捷方式图标只支持网站 favicon、表情字符和名称首字母，不支持自行指定图片地址。

# 改善
1. 优化文本选中，不必要的文本选择去掉
2. 收藏网站图标可以自定义 url
3. 时间位置要可以设置

# 解决方式

## 问题/改善 1：禁用不必要的文本选中
- `global.css` 给 `.page` 加 `user-select: none`（同时补 `-webkit-user-select`），时钟、日期问候、Dock 标签/提示、环境切换、按钮等装饰文字不再被双击或拖选高亮。
- 对 `.page input`、`textarea`、`select`、`[contenteditable='true']` 恢复 `user-select: text`，搜索框与设置表单内的文字仍可正常选中。

## 问题/改善 2：快捷方式图标支持自定义图片 URL
- 配置模型 `ShortcutIconType` 新增 `'image'`（与既有语义区分：`'custom'` 仍是「名称首字母兜底」，`'image'` 的 value 为完整图片地址）；schema 的 `ICON_TYPES` 白名单同步放行，含未知图标类型的配置按既有规则判为 `shortcuts-invalid`。
- 快捷添加弹窗：图标下拉新增「自定义图片 URL（失败时用名称首字）」，选中后出现图标 URL 输入框；提交走 `normalizeUrlInput` 校验——空值报「图标 URL 不能为空」、非 http/https（如 ftp）报「仅支持 http 或 https 地址」、裸域名自动补 `https://`。
- 设置抽屉的快捷方式编辑表单同步支持：`image` 类型在编辑时正确识别并预填图标地址。
- Dock 渲染在 emoji 之后、favicon 之前插入 `<img>`；图片加载失败（onError）自动回退为标题首字。

## 问题/改善 3：时钟九宫格定位
- 配置新增可选字段 `settings.clock?: { position: ClockPosition }`，不升配置版本号；`ClockPosition` 为 9 个值（top/middle/bottom × left/center/right），默认 `bottom-left`，schema 对缺省宽容、非法值拒绝，运行时统一 `?? DEFAULT_CLOCK_POSITION`，旧 v2 配置零迁移。
- 新建 `AppearanceSection` 外观分区（设置抽屉中位于壁纸与备份之间）：3×3 九宫格 `radiogroup`（role=radio + aria-checked、48px 控件高、:focus-visible），点击即时写配置并移动时钟。
- `ClockGreeting` 按配置追加 `clock-block--<position>` 修饰类；CSS 用固定定位实现九宫格——上方留出顶栏安全距离、中部垂直居中、下方避开 Dock，左右贴边、居中用 translate 校正；移动端下沿间距单独加大。
