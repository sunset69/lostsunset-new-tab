# 问题
1. 左上角环境变量下拉框式样有问题


# 改善
1. 本地选取壁纸可以裁剪。
2. 本地选取壁纸保存，之后还可以使用。
3. 添加随机壁纸功能，每次打开新标签页时随机显示一张壁纸。
4. 搜索引擎可以多个选择，默认使用第一个。
5. 搜索引擎可以通过关键词快速调用，例如输入 "baidu"+空格 可以使用百度搜索。
6. 网站快捷方式可以通过可视化添加，不需要打开设置添加。
7. 网页快捷方式可以分类tab选择。

# 解决方式
1. 根因：环境切换器使用原生 `<select>` 并设 `appearance: none` 自定义样式，Chrome/Windows 下此类 select 内文字可被鼠标双击/拖拽选中，出现蓝色选中高亮（即"默认环[境]"里的蓝色块），样式看似损坏。修复：在 [EnvironmentSwitcher.css](../src/newtab/components/EnvironmentSwitcher/EnvironmentSwitcher.css) 的 `.env-switcher` 与 `.env-switcher__select` 上添加 `user-select: none`，禁止 chip 内文字进入选中态；不影响下拉展开、键盘与读屏行为。已重新 `npm run build`，真实扩展页验证蓝色高亮消失、chip 显示正常。
