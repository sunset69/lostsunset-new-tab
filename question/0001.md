# 问题
1. 左上角环境变量下拉框式样有问题


# 改善
1. 本地选取壁纸可以裁剪。
2. 本地选取壁纸保存，之后还可以使用。
3. 添加随机壁纸功能，每次打开新标签页时随机显示一张壁纸。
4. 搜索引擎可以多个选择，默认使用第一个。
5. 搜索引擎可以通过关键词快速调用，例如输入 "baidu"+空格 可以使用百度搜索。
6. 网站快捷方式可以通过可视化添加，不需要打开设置添加。
7. 网页快捷方式可以分类tab选择。

# 解决方式
1. 根因：环境切换器使用原生 `<select>` 并设 `appearance: none` 自定义样式，Chrome/Windows 下此类 select 内文字可被鼠标双击/拖拽选中，出现蓝色选中高亮（即"默认环[境]"里的蓝色块），样式看似损坏。修复：在 [EnvironmentSwitcher.css](../src/newtab/components/EnvironmentSwitcher/EnvironmentSwitcher.css) 的 `.env-switcher` 与 `.env-switcher__select` 上添加 `user-select: none`，禁止 chip 内文字进入选中态；不影响下拉展开、键盘与读屏行为。已重新 `npm run build`，真实扩展页验证蓝色高亮消失、chip 显示正常。

## 改善项（0001 三阶段，配置 v1→v2 迁移）
1. **本地壁纸裁剪**：新增 [image-crop.ts](../src/shared/utils/image-crop.ts) 纯函数（选框移动/角部缩放/比例钳制）与 [WallpaperCropDialog](../src/newtab/components/WallpaperCropDialog/WallpaperCropDialog.tsx) 弹层——拖拽移动、四角缩放、自由/1:1/16:9 比例切换、实时预览；确认时 Canvas 按原格式导出（超 10 MB 提示缩小选区）。上传入口改为「选择图片并裁剪」。
2. **壁纸库**：`AssetStore` 增加 `list()`；壁纸服务改为 `addWallpaperAsset`（只入库不删旧）+ `removeWallpaperAsset`（删除使用中资产先回退默认渐变），设置抽屉「我的壁纸」网格展示全部本地资产缩略图，支持删除确认；备份/恢复缺失资产自动回退。
3. **随机壁纸**：`WallpaperMode` 新增 `'random'` 与 `randomPool`（渐变/内置图/本地资产三组勾选池）；`resolveWallpaper` 注入 random 抽签、不落盘（不污染 updatedAt 与 WebDAV 备份）；池为空回退默认渐变。浏览器验收确认每次打开随机抽中不同渐变。
4. **多搜索引擎**：配置升级为 `searchEngines[]` + `activeSearchEngineId`（v1 单引擎经迁移链自动升级）；设置抽屉列表 CRUD、预设快速添加、上/下移排序，列表第一个为默认引擎；搜索框左端徽标下拉即时切换。
5. **keyword 快速调用**：`search-input.ts` 纯函数实现「keyword+单个空格」触发（大小写不敏感，排除当前引擎）；命中后清前缀、临时切换引擎、提交后自动恢复默认、不落盘；输入恰好等于 keyword 时显示「空格使用 X 搜索」提示。浏览器实测 `baidu␣` + 回车跳转 `https://www.baidu.com/s?wd=...` 且默认引擎保持 Bing。
6. **可视化添加快捷方式**：Dock 尾部固定「+」按钮（≥48px）弹出 [ShortcutQuickAdd](../src/newtab/components/ShortcutQuickAdd/ShortcutQuickAdd.tsx) 表单——URL 规范化校验（缺协议补 https、仅 http/https、行内报错）、名称留空自动取域名、分组下拉、图标三选（favicon/emoji/首字母）；同时支持把链接直接拖拽到起始页（`dnd-link.ts` 按 uri-list → html 锚点 → plain 优先级解析）预填弹窗，无法识别时 toast 提示。
7. **分组 tab**：Dock 上方分组筛选条（「全部」+ 各分组按 order 排序），仅分组数 > 1 时渲染；选中为本地状态不跨会话持久化，空分组显示专属空态文案；分组增删改仍在设置抽屉。

验证：232 个单测 + typecheck + build 全绿；chrome-devtools MCP 真实页面走查（快捷添加表单、拖放预填与 toast、tab 过滤、keyword 触发与跳转、随机模式持久化），控制台零错误。
