# 问题
1. 渐变背景和内置壁纸无法预览了


# 改善
1. 网站快捷方式可以右键操作，如编辑，删除等
2. 分组也可以右键操作，如编辑，删除等
3. docker栏可以自己调节宽度或者双击后自动调整宽度
4. 随机壁纸可以设置里设置是否显示在画面上。画面随机壁纸按钮可以点击切换，也可以右键关闭。

# 解决方式

## 问题 1：渐变/内置壁纸无法预览（根因：grid item 塌缩）
0001 引入「随机池勾选框」时给色块外包了一层 `.wallpaper-cell`，导致 `.wallpaper-swatch` 按钮不再是 grid item：宽度 shrink-to-fit ≈ 0，`aspect-ratio` 高度随之归零；随机卡片也被 4 列网格挤成一字列。修复（`SettingsDrawer.css`）：`.wallpaper-swatch` 加 `width: 100%`、`.wallpaper-cell` 加 `display: flex; min-width: 0`、`.wallpaper-random` 加 `grid-column: 1 / -1` 跨全行。浏览器截图确认渐变 4 色块、内置 2 壁纸、随机卡片全部正常渲染。

## 改善 1/2：快捷方式与分组右键菜单
- 新建 `DockContextMenu` 组件（fixed 定位 + useLayoutEffect 视口钳制、role=menu/menuitem、Arrow/Home/End/Escape/Tab 键盘导航、外部 pointerdown 关闭、选择后焦点正确让位给弹窗）。
- 快捷方式右键：编辑（打开 ShortcutQuickAdd 编辑弹窗，预填网址/名称/分组/图标，保存只更新原条目）、删除（菜单内两步确认「删除 → 确认删除？」，删除后重排 order）。
- 分组右键：重命名（tab 内联输入框，Enter/blur 确认、Escape 取消、空名回退原名）、删除（两步确认，组内快捷方式迁入剩余 order 最小分组；仅剩一个分组时删除无效）。
- `ShortcutQuickAdd` 增加 `editing` prop，复用同一弹窗完成编辑模式（标题/按钮文案切换）。

## 改善 3：Dock 栏宽度调节
- 配置新增 `dock.width?: number`。Dock 左右边缘各有一个隐形把手（role=slider，12px 热区，hover/focus 显形 4×40px 胶囊）。
- 拖拽：pointer capture + 对称收缩（delta×2），拖动中本地预览、松手才落盘；下限 320px，上限视口 -48px。
- 键盘：方向键 ±16（Shift ±64）。双击 / Enter 恢复自动铺满（删除 `width` 字段）。
- 手动宽度时 Dock 以 `width + translateX(-50%)` 居中渲染。

## 改善 4：随机壁纸按钮显隐 + 点击/右键
- 配置新增 `wallpaper.randomButtonVisible?: boolean`（缺省视为显示）与 `wallpaper.lastFixed`（进入随机前固定壁纸的引用）。
- 设置抽屉：随机模式下出现复选框「在画面上显示「换一张」随机按钮」，实时控制 TopBar 骰子按钮显隐。
- 骰子按钮：点击换一张（nonce 重抽，不落盘）；右键退出随机模式——`exitRandomMode` 恢复 `lastFixed`（upload 模式连 assetId 一起恢复），lastFixed 缺失/无效时回退默认渐变。
- `wallpaper-service` 新增纯函数 `enterRandomMode` / `exitRandomMode`（structuredClone，不改入参）。

- chrome-devtools MCP 真实键盘走查五项全过：壁纸预览截图、快捷方式编辑（预填/改名保存）/两步删除、分组重命名（内联 Enter）/删除迁移、宽度键盘 2520→2504 / 拖拽 -100 / 双击恢复自动、随机骰子点击换一张 / 右键退出恢复暮色蓝金 / 复选框显隐；重载后控制台零错误。
