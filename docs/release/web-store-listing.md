# Chrome Web Store / Edge Add-ons 发布材料

版本：0.1.0 ｜ 包名：`lostsunset-new-tab-v0.1.0.zip` ｜ Manifest V3

## 1. 商品信息

### 名称

LostSunset New Tab（落日起始页）

### 一句话简介（≤132 字符，商店摘要）

沉浸式壁纸新标签页：时钟搜索、快捷方式 Dock、内网环境变量，配置可本地/WebDAV 备份。

### 详细描述

LostSunset 起始页把浏览器新标签页变成一个沉浸式工作台：

- **沉浸式首页**：渐变或壁纸背景配合可调遮罩，大号时钟、日期、时段问候与搜索框。
- **自定义搜索**：自行配置引擎名称与含 `{{query}}` 占位符的搜索地址，支持内网搜索。
- **快捷方式 Dock**：增删改查、分组与拖拽排序；支持完整 URL 与 `{{变量名}}` 模板，非法地址在跳转前拦截。
- **多环境切换**：为内网地址定义变量（如 `baseUrl`），一键切换办公/家庭等环境，快捷方式地址随之改变。
- **壁纸能力**：内置渐变与精选风景壁纸，支持上传本地图片（≤10 MB，存于本机 IndexedDB），加载失败自动回退默认背景。
- **备份与恢复**：一键导出/导入 JSON（不含任何凭据），导入前自动备份当前配置；可选连接用户自己的 WebDAV 服务手动上传/下载。
- **隐私优先**：全部配置仅保存在本机浏览器存储，无账号、无统计、无广告；WebDAV 凭据默认不持久化，主机权限按需申请。

### 分类与标签

- 类别：Productivity（效率）
- 语言：简体中文
- 标签：new tab、start page、wallpaper、shortcuts、bookmarks、webdav

## 2. 单一用途说明（Single purpose）

覆盖浏览器新标签页，提供沉浸式起始页（时钟、搜索、快捷方式、环境化地址）以及配置的本地/WebDAV 备份能力。

## 3. 权限说明（逐项）

| 权限 / 能力 | 类型 | 用途 |
| --- | --- | --- |
| `chrome_url_overrides: newtab` | 新标签页覆盖 | 将浏览器新标签页替换为本扩展起始页。 |
| `storage` | 常规权限 | 在 `chrome.storage.local` 中保存用户的引擎、环境、快捷方式与壁纸设置，以及导入前自动备份。 |
| `unlimitedStorage` | 常规权限 | 用户上传的本地壁纸图片以 Blob 形式存入 IndexedDB；解除默认存储配额，避免大图导致保存失败。 |
| `optional_host_permissions: *://*/*` | **可选**权限 | 仅当用户配置 WebDAV 备份时，针对用户填写的**具体服务器源**（如 `https://dav.example.com/*`）弹窗申请，用于经 Service Worker 发送 HEAD/GET/PUT 请求绕开页面 CORS。安装时不授予任何广域权限；拒绝授权不影响其他全部功能。 |
| Service Worker（后台脚本） | 后台执行 | 仅作为 WebDAV 请求的消息代理；无事件时休眠，不做任何轮询或后台收集。 |

不申请 `tabs`、`cookies`、`history`、`bookmarks`、`downloads`、`management`、通知等权限；
JSON 导出通过浏览器原生 `<a download>` 完成，不使用 downloads 权限。

## 4. 隐私实践（Privacy practices）

**数据收集：无。** 扩展不包含任何分析、遥测、崩溃上报或广告 SDK，不注册账号。

**数据存储位置：** 用户配置仅写入本机浏览器的 `chrome.storage.local` 与 IndexedDB，不会自动上传。

**网络请求仅以下三类，且均由用户主动触发：**

1. **搜索跳转**：搜索时浏览器导航到用户自行配置的搜索引擎地址（默认 Bing），不经过扩展服务器。
2. **WebDAV 备份（可选）**：仅当用户填写并操作“测试连接/上传/恢复”时，向**用户自己指定的 WebDAV 地址**发起请求，使用 Basic 认证；密码默认仅保留在内存中，勾选“在本机记住密码”后才存入 `chrome.storage.local`，导出的 JSON 备份文件永远不含凭据。HTTP 明文地址会在界面内显式风险提示。
3. **内置在线壁纸（可选）**：用户选择“山湖清晨/星夜旷野”等在线壁纸时，浏览器向壁纸图源 `trae-api-cn.mchost.guru` 请求一张风景图（URL 仅含固定风景描述词，不含任何用户信息或标识）；不选择则无任何请求，渐变壁纸与本地上传完全离线。

**数据删除：** 用户可在设置中删除快捷方式/环境，或在扩展管理页卸载扩展；卸载即清除全部本地数据。建议卸载前使用“导出配置”留存备份。

**数据出售/第三方共享：** 不存在；不向任何第三方出售或共享用户数据。

**合规勾选建议（CWS Data usage）：** 不收集/出售个人数据；不用于审核之外的目的。WebDAV 与壁纸流量为“用户发起的连接/远程内容”，在表单中按“用户提供的服务器地址”说明即可。

## 5. 提交流程

### Chrome Web Store

1. 开发者后台新建 Item，上传 `release/lostsunset-new-tab-v<version>.zip`。
2. 填写第 1 节文案；截图建议 1280×800：首页、设置抽屉、备份与同步、环境编辑。
3. 隐私实践按第 4 节填写；填写隐私政策链接（可使用仓库内发布说明页面或自有站点）。
4. 权限理由中粘贴第 3 节表格内容（重点说明 `unlimitedStorage` 与可选主机权限）。
5. 提交审核。

### Microsoft Edge Add-ons

1. Partner Center 创建扩展，上传**同一个 ZIP**（MV3 与清单字段兼容，无需改动）。
2. 文案与权限说明同第 1、3 节；Edge 同样要求可选权限的用途说明。
3. Edge 审核可能额外要求新标签页覆盖的必要性描述，使用第 2 节内容。
