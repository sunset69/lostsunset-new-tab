# Chrome / Edge 手工验收清单（M5）

构建：`npm run release` → 产物 `release/lostsunset-new-tab-v<version>.zip`；
或开发模式加载 `dist/`（先 `npm run build`）。

## 环境

- [ ] Chrome 稳定版：chrome://extensions → 开启“开发者模式” → 加载已解压的 `dist/`
- [ ] Edge 稳定版：edge://extensions → 开启“开发人员模式” → 加载解压缩的 `dist/`
- [ ] 工具栏/扩展页图标显示为金蓝落日图标（16/32），无缺图占位

## 新标签页与视觉

- [ ] 打开新标签页被替换为 LostSunset 起始页
- [ ] 时钟、日期、问候语正确，每分钟跨分钟时刷新正常
- [ ] 渐变壁纸 + 遮罩下搜索框与时钟文字清晰可读
- [ ] 1280×800、1366×768 下无横向滚动、无元素重叠

## 搜索与快捷方式

- [ ] 输入关键词回车跳转到结果页，关键词正确编码
- [ ] 保存自定义引擎（名称+含 `{{query}}` 的地址）后搜索按钮与跳转更新
- [ ] 新增/编辑/删除快捷方式，拖拽排序后刷新页面顺序保留
- [ ] 模板缺少 `{{query}}` 或地址非法时保存被拦截并显示错误

## 环境

- [ ] 新增环境与变量，快捷方式使用 `{{baseUrl}}` 后按当前环境解析
- [ ] 切换环境，绑定变量的地址立即改变
- [ ] 重启浏览器后上次环境与配置保留

## 壁纸

- [ ] 切换 4 个渐变立即生效
- [ ] 选择在线壁纸能加载（网络异常时自动回退默认渐变，无白屏）
- [ ] 上传本地 PNG/JPEG（≤10 MB）后刷新页面仍显示；超大文件被拦截
- [ ] 遮罩滑块调节即时生效并持久化

## 备份与 WebDAV

- [ ] 导出 JSON：文件名含日期，内容含 `kind/backupVersion/config`，不含 `credential`
- [ ] 改配置后导入该 JSON：先看摘要 → 确认后恢复，刷新页面保持，导入前配置进入本地自动备份
- [ ] 导入非法文件显示“文件不是有效的配置备份”，当前配置不变
- [ ] WebDAV 测试连接：错误密码提示“用户名或密码错误”；错误端口提示网络失败
- [ ] 首次连接时浏览器弹出**具体源**的主机权限申请；拒绝后有明确提示且不影响本地功能
- [ ] 上传成功（远端不存在直接 201；已存在先弹覆盖确认）
- [ ] 从 WebDAV 恢复：摘要 → 确认 → 恢复成功，自动备份 reason 为 `webdav-restore`
- [ ] 保存设置：勾选记住密码刷新后回填；不勾选刷新后密码留空、其他字段保留
- [ ] HTTP 地址显示明文风险提示

## 安全与包体

- [ ] chrome://extensions 的“错误”按钮无记录，DevTools Console 无红色错误
- [ ] 检查视图（Service Worker）打开后无报错，空闲时可正常休眠
- [ ] ZIP 内不含 `.git`、`node_modules`、`.env*`、`docs/`、`*.map`、系统垃圾文件
- [ ] manifest 权限仅 `storage`、`unlimitedStorage`，主机权限为 optional
