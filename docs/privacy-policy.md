# LostSunset New Tab（落日起始页）隐私政策

最后更新：2026-09-23 ｜ 适用版本：v0.2.0 及以上

本扩展（下称"本扩展"）**不收集、不上传、不出售任何个人数据**。本页说明它的数据存储与网络行为。

## 1. 数据存储

- 所有配置（搜索引擎、环境变量、快捷方式、壁纸设置）仅保存在**本机浏览器**的 `chrome.storage.local` 中。
- 用户上传的本地壁纸图片仅保存在**本机**的 IndexedDB 数据库中，不会离开设备。
- 「导入配置」前自动生成的备份同样只写在本机存储中。
- 卸载本扩展即清除上述全部本机数据；卸载前可使用「导出配置」自行留存 JSON 备份。

## 2. 网络行为

本扩展不包含任何统计、遥测、崩溃上报或广告 SDK。仅存在以下三类由**用户主动发起**的网络访问：

1. **搜索跳转**：用户搜索时，浏览器直接导航到用户自行配置的搜索引擎地址（默认 Bing）。请求不经过本扩展的任何服务器。
2. **WebDAV 备份（可选功能）**：仅当用户主动填写自己的 WebDAV 服务器地址并点击「测试连接 / 上传 / 恢复」时，本扩展才向**该用户指定的地址**发起请求。凭据仅用于该请求（可选在本机记住密码），不会发送给任何第三方，导出的备份文件永远不含凭据。
3. **内置在线壁纸（可选功能）**：用户选择「山湖清晨 / 星夜旷野」等在线壁纸时，浏览器向壁纸图源请求一张图片；请求 URL 仅包含固定的风景描述词，不含任何用户信息或设备标识。不选择在线壁纸则无此类请求。

## 3. 权限用途

| 权限 | 用途 |
| --- | --- |
| `storage` | 在本机保存用户配置与备份。 |
| `unlimitedStorage` | 容纳用户上传的本地壁纸图片（IndexedDB）。 |
| `optional_host_permissions`（可选主机权限） | 仅当用户配置 WebDAV 备份时，针对用户填写的具体服务器地址按需申请；拒绝授权不影响其余功能。 |

本扩展不申请标签页、历史记录、书签、下载内容等权限，不读取网页内容。

## 4. 数据共享

不存在。不向任何第三方出售、共享或传输用户数据。
